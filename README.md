Личный сборник шпаргалок, схем и справочной информации по информационной безопасности, Linux и инфраструктуре. 

Создан для того, чтобы не держать всё в голове и не гуглить одно и то же по десять раз. Вся инфа разложена по полочкам: от механики работы PAM до аудита Docker-контейнеров.


## 💡 Особенности
*   **Наглядно:** Много схем, деревьев зависимостей и таблиц.
*   **Без воды:** Только суть, команды и конфиги.
*   **Обезличено:** Никаких реальных IP, паролей или названий компаний. Только примеры-заглушки (`example.com`, `192.0.2.10`).
